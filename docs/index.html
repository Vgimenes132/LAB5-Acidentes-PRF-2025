Como usar a planilha

  • Para contar acidentes, some a coluna QT_ACIDENTES; para mortes, some QT_MORTOS.
  • Colunas que começam com FL_ são marcações de sim (S) ou não (N), como FL_CURVA ou FL_FIM_SEMANA.
  • Use os filtros do Excel por estado (SG_UF), município, rodovia (DS_BR) ou mês.

Cuidados ao interpretar

  • A base cobre só as rodovias federais atendidas pela PRF. Estradas estaduais, municipais e ruas urbanas não estão incluídas.
  • Mais acidentes em um estado ou trecho não significa, sozinho, estrada pior: quem tem mais quilômetros de rodovia e mais trânsito tende a ter mais registros.
  • 3.823 acidentes têm o total de pessoas menor que a soma de mortos, feridos e ilesos, e 52 têm localização aproximada. Esses problemas vêm da própria fonte. Os registros foram mantidos e marcados nas colunas FL_INCONSISTENCIA_PESSOAS e FL_COORDENADA_IMPRECISA.

Sobre o projeto

Este painel faz parte do Projeto de Curricularização da Extensão "Transformar Base de Dados Públicas em Banco de Dados Acessível à Sociedade", da disciplina Laboratório de Desenvolvimento de Banco de Dados V, do CST em Banco de Dados da Fatec Bauru. O arquivo original da PRF foi tratado e organizado em um banco de dados Oracle. Os números exibidos aqui saem dessa base tratada: nenhum acidente foi perdido no processo.
